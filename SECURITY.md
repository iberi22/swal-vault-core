# Security Policy

## Supported Versions

Use the latest release or the default `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| `main`  | :white_check_mark: |
| Other   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking the "Report a vulnerability" button on this repository.

**Do not open public issues or pull requests for security vulnerabilities.**

## Response Targets

- We aim to acknowledge your report within 5 business days.
- You can expect a status update within 14 days of your initial report.
- We practice coordinated disclosure.
- We currently do not offer a bug bounty program.
