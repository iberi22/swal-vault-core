# Contributing

Thanks for your interest in contributing to `@swal/vault`!

## Workflow

1. **Fork** the repository and clone it locally.
2. **Branch** off from the `main` branch to do your work.
3. Make your changes.
4. **Run Tests** before submitting:
   ```bash
   pnpm test
   pnpm typecheck
   pnpm build
   ```
5. Use **Conventional Commits** for your commit messages.
6. Open a Pull Request against the `main` branch.
